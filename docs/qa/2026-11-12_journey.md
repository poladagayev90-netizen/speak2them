  fake mic). Learners at **390×844**; teacher at **1366×844** and **390×844**.

- **AI analysis**: **stubbed**, so no paid calls. `callAnalysis/{id}` was seeded in the worker's shape, and
  the teacher copies were built with the project's own `analysisPrivacy.teacherAnalysis` /
  `teacherProgress`.
- **Reminders**: the real `practiceSlotTick` ran with the clock moved to T−45 / −44 / −8 / −7 min.

## FAILs — fixed in this commit

1. **HIGH — every new teacher stuck on «Loading...» after sign-up** (T1).
   - *Cause:* the auto-code effect in `src/pages/TeacherUnlock.jsx` listed `autoCode` in its deps and set
     it to `'working'` itself. The cleanup that re-run triggered flipped the effect-local `alive` flag to
     false while `createInviteCode` was in flight. The code was created on the server but never reached
     the page; only a reload showed the cabinet.
   - *Fix:* `TeacherUnlock.jsx:150-183`. A ref guards the single run, and a mounted-ref replaces `alive`.
   - *Verified:* a fresh teacher (T3) lands straight in the cabinet.
2. **MEDIUM — warm-up «Not now» did nothing until a reload** (L7).
   - *Cause:* `warmupDismissedAt` was written, but the field is not in `LIVE_USER_FIELDS`, so the live
     user sync never passed it to Home.
   - *Fix:* `src/App.js:105`. `warmupDismissedAt` and `callCount` are now live fields. With `callCount`,
     the card also leaves Today right after the first real call.
   - *Verified:* the card leaves Today at once and shows in the AInur tab.
3. **LOW — emoji icons and system font on the teacher Invite tab** (T3).
   - *Cause:* 🎓 / 👥 instead of lucide icons. The «Pick from users» `<button>` did not inherit the app
     font.
   - *Fix:* `TeacherUnlock.jsx:806, 1027-1032`. `GraduationCap` / `Users` icons and `fontFamily: inherit`.
