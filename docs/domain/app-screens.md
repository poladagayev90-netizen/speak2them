- **Help & feedback** (2026-11-19, `docs/IDEAS.md` item 5): Profile → Support → «Help & feedback» opens `/feedback` (`src/pages/Feedback.jsx`) — reached only from Profile, never a popup. The learner picks Problem / Idea / Other, writes up to 2000 characters and may attach ONE screenshot (optional), which is shrunk in the browser to a JPEG data URL ≤ 350 000 characters (`shrinkScreenshot`, `src/utils/feedback.js`) and stored inline — no Storage bucket. Doc `feedback/{auto}` = `uid, type, text, appVersion` (`src/version.js`)`, platform` (`Capacitor.getPlatform()`)`, route` (the screen it was opened from, via `navigate` state)`, userAgent, screenshot?, status: 'new', createdAt` (server time). Rules: create only by the signed-in owner with exactly these keys (`buildFeedbackDoc` ↔ `firestore.rules` — change together); read only by the admin (not even the sender); the admin may only flip `status` new ↔ done. Nothing is copied to `users`. The admin reads them in **Admin → Feedback** (admin group, `AdminFeedback.jsx`, newest 60, Open / All, «Done» / «Reopen», screenshot on tap) and gets a push from `notifyAdminFeedback` (Firestore trigger, europe-west4, the same `sendPushToUser(ADMIN_UID)` path as `notifyAdminOnboarding`; links to `/admin?tab=feedback`).
