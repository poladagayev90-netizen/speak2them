# Today / Plan / Partners, chat, online now, app updates, topic sheet on a computer

Moved out of CLAUDE.md on 2026-10-15 so it is read only when a task touches this area. Facts are kept as written; keep this file current when the code changes.

- **Today / Plan / Partners** (Phase 4): the Live tab and its files are gone (`/live` → `/plan`; random search has no client any more, `canPair` stays for old APKs); nav = Today · Plan · Partners · AInur · Profile (Leaderboard inside Profile). Today answers "what now?" with ONE card from `planHeadline()` (`src/utils/planState.js`, pure + tested: setup / next / answer / paused / done / no_match / waiting — never a promise of a partner), then Get ready, then This week. Plan (`src/pages/Plan.jsx`) is the whole week: proposals ("Confirm all"), bookings (join / message / change time / cancel), free times + target (edited through the onboarding wizard with `state.jumpTo`/`returnTo`), and the `planPaused` switch. Partners = the old Chats page + a call button per person. Onboarding v2 adds the **charter** step (`charterVersion`, `charterAcceptedAt` = server time); v1 learners are brought straight back to it with their answers kept. Data: `useMyPlan` (bookings, offers, planStatus, onboarding, attendance).
- **Partners → Coming up** (2026-10-07, `components/plan/ComingUpPartners.jsx`): every booked partner with Message and a clock that opens Plan with that booking's time picker (`navigate('/plan', {state:{openBooking, openTime}})` → `BookingRow autoOpen`). A chat row appears only after the first real call, so a booked partner never talked to was unreachable from Partners.
- **Online now** (2026-10-06, TEMPORARY — remove once the weekly plan carries everyone): `onlineNow` (us-central1) returns up to 12 learners seen in the last 150 s, filtered SERVER-side by the hard pairing rules (block / avoid either way, minor↔adult — the age band is private), never teachers/admin, never anyone with `users.showOnline === false` (Profile toggle). The strip (`OnlineNow.jsx`, `useOnlineNow` — every 60 s while visible) sits on Partners only (removed from Today 2026-10-06); since 2026-10-07 the same list marks partner rows «Online» / «In a call» (and sorts them up), the strip shows only non-partners and stays as one line «Nobody else is online right now»; Call = `navigate('/chat/<uid>', {state:{autoCall:true}})`, so `canPair({direct:true})` still decides. Switch: Admin → Matching «Online now list» = `appConfig/features.onlineNow` (missing = on).
- **Chat** (rebuilt 2026-10-06, WhatsApp-style): `/chat/:peerId` is a fixed full-screen column (App.css `.chat-page`; the bottom nav hides on `/chat/`), the thread `components/chat/ChatThread.jsx` (day lines, grouped bubbles, time + tick inside, memoised bubbles — unchanged messages keep their object in Chat.jsx's snapshot) and `ChatComposer.jsx` (owns its own text so typing never re-renders the 1,900-line call screen; growing textarea, built-in emoji set `chat/emoji.js`, Enter sends on a computer only). Long-press / right-click: Copy, Edit (own text message, **15 min**, rules check `editedAt == request.time` and the window; the bubble says "edited"), Delete for me (localStorage `chatHidden:<chatId>`), Delete for everyone (blank + `deleted`). Report cards (`kind`) can be neither edited nor deleted. Pure helpers `src/utils/chatThread.js` (+ tests). Today shows the daily topic card right under the plan card; Online now is on Partners only.
- **App updates** (2026-10-07, `src/utils/appUpdate.js` + `components/UpdateBanner.jsx`): web/PWA compares the running `main.*.js` with `/asset-manifest.json` (on load, every 30 min, on return to the screen); a newer build shows «A new version… · Refresh» and is applied by itself on return to the screen unless a call / chat / wizard / admin or teacher desk is open — the old instant `location.reload()` on a new service worker is gone (the SW `skipWaiting`s and fetches network-first, so a reload is the whole update). Android: Play In-App Updates (`@capawesome/capacitor-app-update`); `appConfig/version.android = {latest, min}` (Admin → Students → «Android app version»): older than `min` → Play's immediate update + a banner without «Later»; `latest` covers APKs not installed from Play.
- **Topic sheet on a computer** (≥900px landscape, App.css wide block): videos AND pictures (`PictureDescribing`, `.pd-*`) share one layout — media left, words/starters/questions right, ‹ n / N › below, ← → keys. Phones keep the one-column view.
