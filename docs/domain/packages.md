# Practice packages (what is sold, the free practices, enforce switch)

Moved out of CLAUDE.md on 2026-10-15 so it is read only when a task touches this area. Facts are kept as written; keep this file current when the code changes.

- **Practice packages** (2026-10-04, updated 2026-11-22; `functions/packages.js` pure + tested, display mirror `src/utils/packages.js`): what is sold is PLANNED practice a month — default tiers **4 = 6 AZN, 8 = 10 AZN, 12 = locked (price hidden, coming soon)** (`appConfig/billing.packages`; `grantPackage` rejects locked tiers), not minutes. Sales happen outside the Android app on `speaklab.me` and web. **Google Play anti-steering (2026-11-22):** inside the native Android app (`Capacitor.isNativePlatform()`), `/packages` hides all package prices, cards, buy buttons, and external checkout/WhatsApp purchase links — showing ONLY neutral plan status (`Your plan · N practices left`) and how practices count. New learners get **3 free planned practices in total** (`trialPractices`, Polad 2026-10-06; it replaced «2 a week for 4 weeks»), counted from sign-up — or from the day the switch was first turned on (`enabledAt`), whichever is later; no end date, and anyone who has ever had a package is past them. The balance is NEVER stored: `accessState` derives it from the learner's `bookings` (used = attended / no_show / their own late cancel; reserved = confirmed; returned = partner_no_show, "arrived", in-time cancel, cancelled by someone else — the platform's failures cost nothing). A first practice with the team (`source: 'team_intro'`, `docs/domain/planner.md` newcomers) counts as nothing at all. Renewing early moves everything left over; after the end only the returned ones, max `carryMax` 4. Unlimited = admin, `isPremium` ("Make Pro"), cohort, `freeAccessUntil`, a plan other than trial/free — rules-protected fields only, NEVER the client-writable `mode`. Only planned practice is limited — `joinSlotTx` (403 `no-practices-left`), `bookPairTx` for `admin_offer` (409 `student-{a,b}-no-practices`; the one who ran out is told, the other only "did not work out"), `createPlanOfferTx`, `loadPlannerInputs`; teacher pairs, direct calls with friends and AInur are never limited, and the old 60-day lock on the Agora token and the app-wide `TrialExpiredGate` are GONE. **`appConfig/billing.enforce` is OFF by default** (Admin → Students → "Packages ON/OFF", `adminAccess setEnforce`): off = counted and shown, nobody refused. `access/{uid}` (server-only) holds the package + history, written by `adminAccess grant/revoke` (first-ever grant also triggers `creditPartnerOnFirstPurchase` in `partnerLedger`). The app reads `planStatus/{uid}.access` (refreshed by `syncUpcomingCall` on every booking change and by `adminAccess`). `/packages` is NEVER opened by the app: Profile shows "Your plan" only once there is a package or the free practices are used with the switch on; Today/Plan add one quiet line only when the switch is on and nothing is left. The 100-minute counter (`availableTrialMinutes`, `consumeTrialMinutes`) still runs but means nothing.
